# GrailCrest

Grade your Pokémon cards from a scan before you pay to have them graded. Website: https://grailcrest.app

## Download (Windows)

**[Download GrailCrest 1.33.2 for Windows](https://github.com/GrailCrest/grailcrest/raw/main/downloads/GrailCrest-Setup.exe)** (installer, about 14 MB). Already have it? It updates itself.

## Updates

Installed copies check `updates/latest.json` here and update themselves. Every update is signed, and the app
refuses one whose signature doesn't match.

Questions: support@grailcrest.app
